# Supported Formats

BRV scans the selected folder for MP4, M4V, MOV, AVI, MKV, WebM, WMV, FLV, MPEG, MPG, TS, and MTS files. A supported extension means the app can offer the file for processing; FFmpeg must still be able to decode its streams.

Resized copies are written as broadly compatible MP4 files with H.264 video, `yuv420p` pixel format, and AAC audio.
