# Getting Started

Download [Batch Resize Video from Microsoft Store](https://apps.microsoft.com/detail/9NM4PKDTHCBL), then open it from the Start menu.

1. In **Input folder**, choose **Browse** and select a folder containing videos. BRV scans that folder only, not subfolders.
2. In **Resize**, enter an even pixel width and height, or select a social-media or common video-size preset. The selected preset is highlighted and updates both size fields.
3. Choose **Fit within** to preserve all content with black bars, or **Crop to fill** to fill the target frame. With Crop to fill, use **Position** for a quick nine-point focus or **Draw crop frame** to place a locked-aspect crop box on the original preview.
4. Check **Frame preview** using the Original, Resized, or Split view. It renders a real frame from the first video in the selected folder.
5. In **Output**, accept the separate `resized` folder or choose another destination. Add a filename suffix if useful.
6. Select **Resize videos**. The activity log records completed, skipped, and failed videos.

BRV creates new H.264/AAC MP4 copies. Source videos are not changed.

## Help and support

Select the **?** icon in the app to reopen the built-in getting-started guide. The **megaphone** menu provides direct actions for feedback, support, a Store review, and app information.

Before a large batch, use the real-frame preview and test a short representative video—especially when changing the aspect ratio or using **Crop to fill**.
